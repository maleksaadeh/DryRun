# What does this app do?
It uses infrared technology (only available on iPhone pro models, 12 and onwards) to detect a wall, and then render a paint color only on the wall.
## Why this idea?
There are apps out there that do something KIND OF like this, but the infrared idea allows us to take into account lighting and shadows. This is still something finicky, and will need work and testing with real paint colors.
## Only three colors?
I added 3 default colors to choose from - but also added the ability for the user to add their own. They need a Light Reflectance Value as well, though (shadows are important)

## Shortfalls
As I've worked on this app, I've learned that dark colors absorb IR light. So the app has difficulty picking up dark walls.
